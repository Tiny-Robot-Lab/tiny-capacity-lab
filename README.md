# Tiny Capacity Lab

Tiny Capacity Lab is a Tiny Robot Lab project for experimenting with how to
observe and understand the capacity of AI development tools.

The initial experiment focuses on obtaining trustworthy quota and reset
information from Muse Code and Antigravity through their existing local CLI
interfaces on macOS.

This project starts small intentionally.

See [Experiment 0001](docs/experiments/EXPERIMENT-0001.md) for the initial
research question, scope, evidence requirements, and non-goals.

## Research notebook

Exploratory observations correlating development tasks, capacity movement,
engineering outcomes, review findings, and rework are preserved in the
[AI Development Capacity Research Notebook](docs/evidence/AI-DEVELOPMENT-CAPACITY-RESEARCH-NOTEBOOK.md).

The notebook is working evidence for a possible later experiment. It is not
part of the Capacity Observation v1 contract or Experiment 0001 implementation
scope.
